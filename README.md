# Raagav — A quiet corner

A personal website subtly inspired by Henri Rousseau’s Fight Between a Tiger and a Buffalo. Plain HTML, CSS, and JavaScript; no installation or build step needed.

## Publish with GitHub Pages

1. In GitHub Desktop, commit these files and click **Push origin**.
2. Open your repository on GitHub, then **Settings → Pages**.
3. Choose **Deploy from a branch**, select **main** and **/(root)**, and save.
4. Once deployment finishes, open the website link shown in Pages in a private browser window.
